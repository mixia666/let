An AI coding agent built a neon snake game (Pulse Serpent, in game.html) from a single prompt and made a short video of the build; the video is posted on X as this entry, and main.ts hands the post's address in POST.json to the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
